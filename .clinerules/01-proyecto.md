# Proyecto

Sitio web estático con **Astro 7**, **Tailwind CSS 4** y **Motion 14**.
Lo trabaja un estudiante que sabe HTML y CSS, pero está aprendiendo Astro:
cuando uses algo propio de Astro (props, `map()`, `class:list`, `<slot />`), explícalo en una frase.

## Prohibido

- Instalar paquetes o usar CDNs sin preguntar antes (nada de React, Vue, Bootstrap, jQuery, librerías de iconos).
- Crear `tailwind.config.js`: Tailwind 4 se configura en `src/styles/global.css`.
- Usar Google Fonts, imágenes o scripts de URLs externas.
- Ejecutar `npm run dev`: el estudiante ya lo tiene abierto en otra terminal.
- Modificar `package.json`, `astro.config.mjs`, `tsconfig.json`, `.prettierrc.json` o `.vscode/` sin que lo pidan.
